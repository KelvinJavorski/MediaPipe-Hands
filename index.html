Harpa de Ar

  1. Faça pinça (polegar + indicador) com as duas mãos e afaste-as: uma corda estica entre elas.
  2. Solte a pinça: a corda fica presa onde você deixou.
  3. Passe o indicador pela corda para tocar. Quanto mais rápido, mais forte. Corda longa = grave, curta = agudo.
  4. Faça pinça em cima da ponta de uma corda para agarrá-la e mudar o comprimento, enquanto a outra mão toca. Encolha até sumir para apagar.

No iPhone, desligue o modo silencioso para ouvir.
